# LISA (Light In Sorting Affairs)

> **The "Kryptonite" for the IT world's hunger for energy.**

LISA is a mechanical, fully offline data processing system. It is built from wood, marbles, and punch cards, and requires **zero electricity, zero servers, and zero cloud**.

## 💡 The Idea

The modern IT world burns unimaginable amounts of energy to store and retrieve static factual knowledge. LISA shifts this task back into the realm of physics. It is a deterministic sorting machine that processes knowledge through gravity and mechanics.

If we can manage to move even a fraction of our data processing (the 70% of static factual knowledge) out of the power grid and into mechanical systems, we can massively relieve the burden on data centers. LISA is not a replacement for modern processors; it is the physical answer to the "last mile" of data storage.

## ✨ Features

- **100% Offline (Air-Gap):** No network connection, no firmware vulnerabilities, no data leaks. The ultimate form of data security.
- **Energy Efficient:** Zero electricity consumption for the actual data processing.
- **Deterministic:** The same input always produces the same output. No software bugs, no crashes.
- **Open Source:** Freely available for schools, makers, researchers, and anyone who wants to make knowledge tangible again.
- **Haptic Learning:** Perfect for education. Children and teenagers literally *grasp* how algorithms and logical decision trees work.

## ⚙️ How it works

1. **The Topic Card:** Sits on top and defines the "address" of the search.
2. **The Question Cards:** Contain the knowledge in the form of holes and are pushed into the box from the front (similar to drawers).
3. **The Marbles:** Are dropped in from above. They fall through the holes and get stuck at the exact point where a card answers "No".
4. **The Result:** The depth at which the marbles stop provides the logical answer to the query. By swapping and rearranging the card layers, the entire system can be reconfigured.
